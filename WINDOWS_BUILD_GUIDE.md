# SIGNAL TERMINAL — Windows Installer Build Guide

This guide explains how to build the **SIGNAL TERMINAL** Windows installer from the source code.

> **Important:** This ZIP contains source code and build scripts, **not a prebuilt Windows EXE**.
>
> The Windows application should be built on a Windows machine (or in a Windows build environment), rather than on a Linux-based environment.

---

## Requirements

Before starting, make sure you have:

* Windows PC
* Python **3.11 x64**
* Inno Setup 6 — only required if you want to create the `Setup.exe` installer

---

## 1. Extract the Project

Extract the project somewhere writable.

For example:

```text
C:\Users\YourName\Desktop\SIGNAL_TERMINAL
```

Avoid building the project from a restricted or read-only directory.

---

## 2. Install Python

If Python is not already installed, install:

**Python 3.11 x64**

During installation, make sure Python is added to your system `PATH`.

You can verify the installation from Command Prompt:

```cmd
python --version
```

Expected output:

```text
Python 3.11.x
```

---

## 3. Install Inno Setup

If you want to create a Windows `Setup.exe` installer, install **Inno Setup 6**.

Inno Setup is used to package the built application into a user-friendly Windows installer.

You do **not** need Inno Setup if you only want to build the application executable.

---

## 4. Build the Windows Application

Open the project folder:

```text
SIGNAL_TERMINAL/
```

Then double-click:

```text
build_windows.bat
```

Wait for the build process to complete.

The build script handles the required packaging process and generates the Windows application build.

---

## 5. Create the Installer

After the application build is complete, open:

```text
installer.iss
```

with **Inno Setup Compiler**.

Then:

1. Open `installer.iss`
2. Review the configuration if necessary
3. Click **Compile**
4. Wait for the compilation to finish

The installer should be generated at:

```text
Output\SIGNAL_TERMINAL_Setup.exe
```

---

## 6. Distribute the Installer

Once the build is successful, the file you should send to another Windows user is:

```text
SIGNAL_TERMINAL_Setup.exe
```

The recipient should be able to install the application through the normal Windows installer.

After installation, the application can be launched from the **Start Menu** and, depending on the installer configuration, optionally from a **Desktop shortcut**.

The end user should **not need to install Python or run the BAT files** when using the compiled installer.

---

## Build Flow

The overall process is:

```text
Source Code
     ↓
build_windows.bat
     ↓
Windows Application Build
     ↓
installer.iss
     ↓
Inno Setup Compiler
     ↓
SIGNAL_TERMINAL_Setup.exe
     ↓
End User
```

# Troubleshooting

## `build_windows.bat` fails

If the build script fails:

1. Do not close the terminal immediately.
2. Copy the complete terminal output, or
3. Take a screenshot of the error.

The full error output is useful for identifying the exact build failure.

---

## The installed application starts but data is unavailable

If the installed application launches successfully but market data is unavailable, this is generally a **market-data/provider issue**, not an installer issue.

Check the application's live-data provider and connectivity before troubleshooting the Windows installer.

---

## Market Data Limitations

The current live provider uses **Yahoo Finance public FX chart endpoints**.

These endpoints:

* Are not a licensed broker feed.
* Do not provide Quotex OTC prices.
* May not support every requested symbol.
* May not update every timeframe consistently.
* Should not be treated as proof of live OTC price accuracy.

Differences between the application's chart and another platform's chart can therefore occur because the underlying data sources may be different.

> **Do not treat generated signals as guaranteed trading outcomes or as proof of live OTC market accuracy.**
